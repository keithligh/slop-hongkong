# Hong Kong world origin

Decision record for the next geodata pipeline. The running build still uses the upstream Manhattan frame in `tools/geo-base.mjs` and `js/nyc-geodata.js`. These values are documentation only.

## Origin

Central, Hong Kong — Statue Square / Chater Road.

- LAT0 = 22.28088
- LON0 = 114.15979

Mean of OpenStreetMap Statue Square nodes near Chater Road.

## Why Central

In a 1.2 km sample, Central had the densest OpenStreetMap coverage among Central, Admiralty, and Tsim Sha Tsui: buildings, height tags, and named features.

## Bearing

v1 bearing is true north. A rotation onto the harbour axis is deferred. No offset angle is chosen in this step.

## v1 extent

Hong Kong Island, Kowloon, and Victoria Harbour.
